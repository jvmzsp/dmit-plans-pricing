## 三条线路系列：Premium、Eyeball、Tier 1 的本质区别

DMIT 的套餐不是按 CPU 内存分系列，而是按**网络线路**分系列，同一个机房下通常有三档可选。这个设计第一次看会有点绕，但理解了之后选套餐会简单很多。

**Premium（Pro）系列**走电信 CN2 GIA 三网回程 + 去程优化，是 DMIT 的旗舰线路。官方明确承诺路由质量，晚高峰丢包率低、延迟稳定，适合对国内访问体验有要求的场景，比如外贸建站、面向国内用户的代理节点、低延迟游戏加速。价格最高。

**Eyeball（EB）系列**走联通 9929 或移动 CMIN2 回程，属于"尽力优化"档。官方没有像 Premium 那样的硬性路由承诺，但实际晚高峰表现比纯国际线路稳得多，价格比 Premium 便宜一截，是预算有限但又想要国内优化的折中选择。

**Tier 1（T1）系列**是纯国际线路，没有任何中国大陆方向的专项优化。价格最便宜，但国内直连体验取决于运营商出口，晚高峰可能拥堵、丢包。适合服务海外用户、跑国际业务、做中转落地节点或备用机，不适合直接面向国内用户提供访问服务。

> 一句话总结：T1 是能到目的地的拼车，EB 是速度不错的快车，Pro 是体验最好的专车。价格也按这个顺序递增。

## IP 被墙怎么办：Pro/EB 和 T1 政策不同

IP 被墙是 VPS 用户最头疼的问题之一，DMIT 的 IP 更换政策按线路系列区分，差异不小。

**Pro 和 EB 系列的免费换 IP 条件**（需同时满足）：
- 实例已购买至少 7 天
- 距离上一次 IP 更换至少 15 天
- ICMP 和 TCP 所有端口都已被封禁
- 服务剩余有效期不少于 7 天

符合以上条件可以免费换 IP。如果只是部分端口在部分地区不可达，或实例购买不足 7 天，需要付费 $5/次，间隔至少 7 天。另外也可以选择 IP Care+ 附加服务，每 7 天就能免费换一次。

**T1 系列只能付费换**：购买 24 小时后可申请，每次 $5，间隔至少 3 天，且**不保证敏感地区（中国大陆、俄罗斯等有网络审查的地区）的第一次连接可用性**。如果对 IP 能否在国内访问有要求，购买 T1 时可以加 IP Guarantee+ 附加服务，开机即保证 IP 可用，否则遇到被墙 IP 要自己发工单花钱处理。

> 提示：Premium 和 Eyeball 网络配置的实例官方保证全球范围内的第一次连接可用。如果开机就发现 IP 被封，可以直接提交工单免费更换。T1 没有这个保证。

## 退款政策：3 天全额、30 天按剩余价值退

DMIT 的退款政策比很多同行更明确，规则如下：

**全额退款**（扣除支付网关手续费）：购买不超过 3 天，且流量使用不超过 30GB。

**部分退款**（扣除支付网关手续费）：购买不超过 30 天，按剩余价值计算——如果按已用流量算的价值高于按剩余时间算的价值，就按剩余流量退，否则按剩余时间退。

**不退款的情况**：同一系列已经有 3 次退款记录；被 DDoS 攻击；网络质量不好；IP 地理位置原因；任何滥用导致的损失；违反 TOS 单方面发起支付争议；IP 在部分地区不可达但已用流量超过 3GB。

退款可以选择退到 DMIT 账户余额（无手续费）或退到原始支付方式（扣除支付网关手续费）。

建议先用月付测一个月，确认 IP 质量、延迟、晚高峰表现符合预期，再转年付锁价。不要一上来就买年付，万一碰到被墙的 IP 或网络不符合需求，退款会有损耗。

## 流量超量不会停机，只会限速

这是 DMIT 一个比较友好的设计。当套餐标定的流量额度耗尽后，DMIT 不会直接停机，而是把带宽降速到一个较低的速度让服务器继续运行，直到下一个计费周期流量重置。LAX Pro 和 EB 全系都提供超量降速不停机服务，WEE 系列超量后限速 100Mbps（LAX）或 50Mbps（HKG/TYO）无限跑。

对跑任务、做中转、搭代理的用户来说，这意味着不用担心半夜流量跑超被断网。如果你想要更宽松的超量规则，也可以在 VM 控制面板手动调整超量处理方式。

**Q：DMIT 有优惠码吗？**
